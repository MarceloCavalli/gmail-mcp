# Política de Privacidade — Gmail MCP

*Última atualização: 26 de outubro de 2026*

## 1. Quem somos

Este aplicativo é de uso pessoal e privado de Marcelo Antônio Cavalli. Não é oferecido ao público nem comercializado.

## 2. Finalidade

O aplicativo permite que um assistente de inteligência artificial, executado localmente no computador do titular, leia, pesquise, organize, redija e envie e-mails na conta Gmail do próprio titular, sempre por comando dele.

## 3. Dados acessados

Mediante autorização expressa do titular via login do Google, o aplicativo acessa mensagens, threads, anexos, metadados, marcadores e rascunhos do Gmail, apenas das contas que o próprio titular autorizar.

## 4. Armazenamento

Os tokens de acesso ficam salvos apenas no computador local do titular. O conteúdo dos e-mails é processado sob demanda e não é armazenado em servidores do desenvolvedor. Nenhum dado é vendido, compartilhado ou transferido a terceiros, exceto o necessário para o funcionamento do assistente de IA escolhido pelo titular.

## 5. Uso Limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a [Política de Dados do Usuário dos Serviços de API do Google](https://developers.google.com/terms/api-services-user-data-policy), incluindo os requisitos de Uso Limitado. Os dados não são usados para publicidade nem para treinar modelos de IA de uso geral.

## 6. Revogação

O titular pode revogar o acesso a qualquer momento em https://myaccount.google.com/permissions e apagar os tokens locais.
